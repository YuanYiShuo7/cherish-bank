# 八月以阴天小雨结束

- 伤心的人啊，南京在下雨。

- 上午晕晕沉沉醒来，难过，惆怅，不知为何而悲。

- 中午吃了椰子鸡。

- 尝试下午洗个澡躺床上歇一会儿恢复状态，学了一会儿数学，上声乐课。

- 声乐课因为紧张找不到音被冷静处理，感官都清醒了，发现很多事情都没有那么简单，没有长期科学的训练很难有成效。我一直是有些浑浊的，在阴雨连绵的日子，以前我不懂晴天的珍贵，可失去了晴天，我也就失去了也醒来就能看到斑驳阳光的早晨。

- 晚上饿。吃西安面馆，饿。吃汉堡王，饿。健身，饿。吃老母鸡泡面，饿。

- 发现数学分析的东西真多。

- 我发现写日记是必要的，以前我是个成熟的人，有丰富的经历，可惜生了一场大病忘了很多事情，就变得不再成熟。
